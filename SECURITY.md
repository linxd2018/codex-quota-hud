# Security and private data

Do not attach Codex authentication files, API keys, cookies, configuration
directories, task databases or unredacted logs to public issues.

For a suspected vulnerability, use GitHub's private vulnerability reporting
when available. Otherwise request a private reporting channel without posting
exploit details or sensitive data in the public issue.

Automatic continuation is opt-in. Review the interrupted task and its existing
permissions before enabling it. Unknown delivery outcomes are not blindly retried.
Only run one continuation monitor against the same local account state.
