# HUD 1.1 使用说明

双击根目录唯一的 `启动额度HUD.vbs`，或直接运行 `release/CodexQuotaHUD/CodexQuotaHUD.exe`。程序自带 Python 与 Qt；本机仍需已登录的 Codex CLI 和 Node.js。路径发现失败时，在设置里选择 CLI 与 Node.js。

- 自动接续：绿色开启，红色关闭；每次启动默认关闭。仅处理明确因额度中断的任务。
- 设置：调节背景透明度、磨砂、鼠标穿透和“随 GPT 启动”。手动退出 HUD 后不会反复拉起。
- `Ctrl+,` 打开设置，`Ctrl+R` 刷新额度，`Ctrl+L` 查看恢复记录。
- `Ctrl+Alt+P` 切换穿透，`Ctrl+Alt+H` 隐藏或显示；托盘也可恢复窗口。重新显示时自动解除穿透。
- 关闭 HUD 会停止后续自动接续；已经交给 Codex 的任务继续由 Codex 处理。

额度查询使用只读接口，更新失败会明确显示过期。“已投递”表示命令被接受；“已确认”表示找到本次接续标记；“投递不明”不会盲目重发。

## 数据

配置、日志和任务数据库位于 `%LOCALAPPDATA%/CodexQuotaWatchdog`。请不要将该目录中的账号信息、日志或数据库提交到仓库。

同一台电脑不要同时开启多个自动接续实例。

## 开发与打包

日常使用不需要开发环境。需要开发时，在项目根目录执行：

```powershell
py -3 -m venv .build-venv
.build-venv/Scripts/python.exe -m pip install -r source/requirements-build.txt
```

进入 `source` 后运行测试，或双击其中的 `打包HUD.bat`：

```powershell
cd source
../.build-venv/Scripts/python.exe -m unittest discover -s tests -v
```

打包输出仍为根目录 `release/CodexQuotaHUD`。分享程序时需要整个目录，不能只复制 EXE。
